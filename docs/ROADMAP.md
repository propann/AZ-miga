# Feuille de route AZ-miga

## Phase 0 — Fondation (documentation)

- [x] Référentiel GitHub initialisé.
- [x] Architecture et revue des solutions publiées.
- [x] Démarche de diagnostic non destructive définie.
- [ ] Référence exacte de l'écran 10 pouces.

## Phase 1 — Matériel

- [ ] Raspberry Pi OS ARM64 démarre.
- [ ] DSI fonctionne au mode natif.
- [ ] Clavier, souris et audio fonctionnent.
- [ ] Température, stabilité et alimentation vérifiées.

## Phase 2 — Émulation

- [ ] Amiberry démarre sur DSI.
- [ ] A500 / Kickstart / média de test validés.
- [ ] A1200 AGA / Workbench validés.
- [ ] Disque dur virtuel persistant.

## Phase 3 — Expérience

- [ ] Audio PAL 50 Hz sans coupures perceptibles.
- [ ] Gestion manettes et clavier adaptée.
- [ ] WHDLoad testé avec contenus licites.
- [ ] Benchmarks du profil RTG/JIT.
- [ ] Échanges de fichiers avec l'hôte.

## Phase 4 — AZ-miga OS experience

- [ ] Sélecteur de profils A500 / A1200 / Advanced.
- [ ] Démarrage automatique et retour maintenance.
- [ ] Sauvegardes/restauration des configurations et disques.
- [ ] Habillage graphique rétro cohérent avec le DSI.
- [ ] Profil musique : ProTracker et export de modules.

## Règle de validation

Ne cocher un test matériel qu'avec résultat constaté sur le vrai Pi 4. Consigner modèle d'écran, version Raspberry Pi OS, version Amiberry, résolution, fréquence, audio et limites.
