AZ-miga experimental image: complete Raspberry Pi OS first-boot setup.
Amiberry opens on login. Add legally acquired Kickstart and Workbench media.
Do not apply a random DSI overlay: check the 10-inch panel model.
Disable autostart: sudo mv /etc/xdg/autostart/az-miga.desktop /etc/xdg/autostart/az-miga.desktop.disabled
No ROM, Workbench or games are included.
